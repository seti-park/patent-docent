### §1.3 NEW BLOCKER 계수 방식

| 항목 | 확정 |
|---|---|
| **세는 단위** | **감수자가 `NEW BLOCKER` 로 라벨한 항목 1건 = 1.** 총괄이 격을 다시 매기지 않는다 |
| **의뢰 간 중복** | **합산하지 않는다.** 둘 이상의 의뢰가 **같은 결함**(같은 코드 좌표 · 같은 기제)을 들면 **1건**으로 세고 판정표에 「의뢰 A·B 공통」으로 적는다. 선례 = PD-M1.8 의 C′-1·D 가 독립으로 닿은 S7 배제 결함(`D-20260819-03` §4.1) |
| **같은 의뢰 안의 하위 항목** | 감수자가 번호를 붙인 단위를 그대로 따른다. 한 BLOCKER 아래 예시가 여럿이면 **1건**이다(PD-M1.8 의 D ① 이 위조값·`null` 위장 둘을 한 항목으로 든 형태) |
| **총계의 보고 형태** | **의뢰별 원계수와 중복 제거 후 계수를 둘 다 적는다.** 하나만 적으면 다음 라운드가 어느 쪽과 비교할지 모른다 |
| **처분 의무** | 전건에 `수용` · `부분 수용` · `기각` · `이연` 중 하나를 배정한다. **무처분 소멸은 금지**(재정 N7 의 정신 — 압축 보존이 문언을 잃게 한 사건의 처분 판) |
| **★ Q4 동결과의 관계** | **배제 어형의 반례 지적은 정당한 지적이며, 이 라운드의 처분은 「등재하고 고치지 않음」**이다(재정 2026-08-31 Q4). 그런 지적은 `기각`이 아니라 **`이연`**으로 적고 해제 조건(PD-M4 의 `numeric.exhaustive`·`numeric.unreviewed-use` 구현 + 실물 런 1회)을 함께 적는다. **기각으로 적으면 지적이 틀렸다는 뜻이 되고 그것은 사실이 아니다** |

### §1.4 감수 4의뢰 각각의 완주/사망 판정 기준

**격 어휘는 재정 S8 부칙이 정한 것을 그대로 쓴다** — `complete` · `recovered(resume)` ·
`partial(events)` · `dead`. 아래는 그 넷을 **무엇으로 가르는가**의 사전 확정이다.

| 격 | 판정 기준 (전부 기계 확인 가능) |
|---|---|
| **`complete`** | ① 레인 로그 꼬리에 **`EXIT=0` 마커**가 실재 ② 산출 파일에 감수자의 **최종 판정문**(`VERDICT` 또는 `판정:` 머리)이 실재 ③ 그 판정문이 발주문의 **필수 보고 항목을 전부** 든다(의뢰별 §1.5). 셋 다 충족 |
| **`recovered(resume)`** | 1차 세션이 죽고 `codex exec resume` 로 이어 받아 위 3항을 충족. **`-c 'sandbox_workspace_write.writable_roots=[…]'` 재지정이 실호출 문자열에 실려야 한다**(씨앗의 `--add-dir` 는 상속되지 않는다 — LANE-RUNTIME 함정 F) |
| **`partial(events)`** | 최종 판정문이 없고 **rollout jsonl 에서 발굴한 이벤트**만 있는 경우. **판정표 자격 없음 — 참고 전용**이며 미확인 표기 항목은 커버리지에서 제외한다(재정 S8 부칙 2) |
| **`dead`** | 위 어느 것도 아니다. 산출 0바이트이거나 EXIT 마커가 없고 rollout 발굴도 실패 |
| **사망의 관측 규칙** | 폴링 간격 **30초** · **무진전 임계 300초**(산출 파일 바이트 수가 300초 동안 불변이면 진전 없음으로 보고 프로세스 생존을 `[ -d /proc/$PID ]` 로 직접 확인한다 — `pgrep -f` 자기매칭 금지). **시간 상한(CAP)은 걸지 않는다**(재정 S6) — 끊는 것은 도구 호출의 600초 상한뿐이고 그래서 배경 실행이다 |
| **재실행 여부** | 재정 S8 부칙 4 그대로 — **회수분만으로 진행할 수 있고** 재실행은 발주자(총괄)의 판단이다. 이 라운드의 사전 방침: **`dead` 1건까지는 회수 시도 후 재실행 1회**, 2건 이상이면 자원 상태를 상신하고 멈춘다 |

**★ 앵커 규정은 격보다 위다**(재정 S8 부칙 1). **앵커가 있는 지적은 격과 무관하게 실재 확인으로
판정한다.** 그 역도 이 리포가 이미 세웠다 — 실재 확인을 통과하지 못하는 앵커는 그 인용을 지탱하지
못한다(`D-20260819-03` §3.5 의 유령 좌표 사건). 이번 라운드도 **인용된 좌표를 전건 실재 확인**한다.
