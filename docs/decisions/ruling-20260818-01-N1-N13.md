## §1 재정 원문 (2026-08-18, 13건)

**N1. 최종 심급 입력 경계 = P1′ (구 §9.15/B-03 해소).** 격리 기준을 열거에서 성격으로 승격: **차단 = 수정 루프가 산출한 모든 것**(심판 대상인 최종 초안만 예외 — 수정 이력·게이트 로그·점수·비평 메모·계기 데이터·이전 판정 포함), **자격 = 루프 개시 전 동결물**(계약 전체·동결 재료 명세·숫자 화이트리스트·반복 횟수 k·슬롯 선언). 루프 전/후는 생성 시점·출처로 기계 판별. 제공은 최소 필요 원칙: 거부권 3종 임무에서 도출되는 목록만(최종 초안·재료 명세·계약·화이트리스트·k·슬롯 매핑 **발췌본** — 블루프린트 전문 아님, 논지·의도 서술 배제). 판정문에 열람 파일 목록+버전 해시 명기. 헌장 D8의 최종 심급 문구를 이 정식화로 1문장 정정.

**N2. 용어 규칙 = Q-a″ (구 M-07 해소).** 용어 관련 **자동 검사를 완전 제거**(거부권도 자문도 아님 — 검사 항목 자체 소멸). 원칙은 펜 계약의 긍정형 지침으로 이전, 문안: "각 전시 스톱은 구성요소 하나를 다룬다. 그 구성요소를 설명하는 데 필요한 새 용어는 등장한 자리에서 한 줄로 풀어준다. 풀이 없는 용어를 쌓지 않는다." (숫자 캡 없음 — 트윗의 단위는 용어가 아니라 구성요소다.) `new_terms`는 설계→펜 작업 메모로 존치하되 **어떤 게이트도 법으로 읽지 않음**을 명시. 용어 걸림의 유일한 검증층 = 계기(Haiku 시독) 실측임을 스펙에 명시.

**N-D11. 헌장 D11 재구조화.** D11을 정체성 4문장으로 축소: ① 채널 = X 스레드, EN(장문 포스트 아님 — 피드 물리) ② 형식의 단위 = 전시물: 1트윗 = 1전시 스톱(도면 중심), 트윗 수는 전시물 수의 종속변수 ③ 스레드는 슬롯 아크(훅 → 전시 스톱들(반전 포함) → 착지 → 꼬리)를 따른다 ④ **형식의 모든 수치는 헌장이 아니라 형식 파라미터 시트가 관할하며, 시트는 배치 리뷰의 재정으로 교정된다.** 수치 전부를 **형식 파라미터 시트**(`contracts/` 신설, 버전 관리)로 이동, 각 항목에 출처 태그: `[물리]`(플랫폼 강제 — 280자 가중 계산·이미지 ≤4장·피드 접힘; 갱신=플랫폼 변경 시만), `[전승]`(외부 경험칙 — 본문 상한 260자·해시태그 0·링크 꼬리 격리; 환류 검증 2순위), `[가설]`(우리 추정 — 트윗 6~12·본문 스톱 하한 180자·스톱 이미지 ≥1·문장 ≤2·소비 3~4분·이미지 원칙 1장; 환류 검증 1순위). v0 값 = 기존 재정값 그대로(R5·R6의 역할 차등·슬롯 개수 규칙 포함). 태그의 의미(언제 무엇으로 의심하는가)를 시트 머리에 정의.

**N3. 스톱 형태 규칙 = S1 (구 §9.17 해소).** `format.stop-shape` 시트 등재 + **거부권 유지**. 정의 정정: 이미지 요건 = "**편집 자산**(크롭 도면 또는 자작 다이어그램·수치 카드) ≥1"(R11 잠정 규칙과 정합 — 원본 도면만으로 한정 금지). 문장 계수 규칙(약어 예외 목록 포함)을 계약에 명시(결정론 보장). ≥1·≤2 모두 `[가설]` 태그 = 배치 리뷰 최우선 교정 후보 명기. 적용 = 본문 전시 스톱(반전 포함) 전용.

**N4. 점수 린트 확장 = T1 (구 §9.18 해소).** 별점(연속 심볼)·학점형 등급·백분율 척도(N/100) 3종 패턴 확장 승인 — 단 **4요소 서식**(패턴 정의·검출 방법·예외/반례·재정 기록) + **반례 golden 동반**("A-1 구조"·"automotive-grade" 같은 정상 표기가 걸리면 안 됨 — 반례를 회귀 스위트에 동시 편입). 관할 명시: **자문 산출물(소견·계기 보고·비평 메모) 전용** — 본문 스레드는 대상 아님. 패턴 목록 버전 관리 + 판정문 버전 명기, 이후 확장은 배치 리뷰 재정.

**N5. 공허 가시화 = U3 (구 §9.21 해소).** 특수 날인 제도를 정량 보고로 일반화: **모든 게이트 검사 행은 (검사 ID · 적용 규칙/목록 버전 · 검사 대상 수 · 위반 수 · 상태)를 보고**한다. 공허 2종이 자동 가시화됨 — 법이 빈 경우("규칙 0항"), 대상이 빈 경우("대상 0건"). R7의 카탈로그 공허 날인은 이 서식의 자동 귀결로 흡수(재정 위반 아님 — 일반화 이행). 판정 행 서식을 계약 파일로 고정. 회귀 표본에 "숫자 0건 스레드" 추가(공허 표기 정확성 테스트).

**N6. 재정 원장 제도 = V1 (구 M-09 해소).** `docs/decisions/`에 재정 원장 등재: ① 이 발주문의 N1~N13 전문 = **원문**으로 등재 ② R1~R12(M0.5 발주문의 재정 원장 절) = **재구성본** 표시로 등재(사후 재구성을 원문으로 위장 금지) ③ D1~D15 원 재정 = 재구성본 표시. 규율 성문화: **재정 발생 → 원장 등재 → 문서 반영**(원장=상류, 헌장·스펙=하류; 감수는 원장↔문서 대조로 전사 충실성 검증). 원장 파일 형식: 일자·안건 ID·재정 원문(원문/재구성본 구별)·결정 요지·반영처 링크.

**N7. 감수 기록 규율 = W1 (구 §9.23 해소).** ① 모든 외부 감수·검증 산출물은 수령 즉시 **원문 그대로** `docs/lessons/`에 보존, 처분표·요약은 원문 포인터로만(M0.5부터 기시행 — 소급 명문화) ② 이번 재감수 발주 요건에 "**M0 미처분 지적(M20·M21 등)의 재도출**" 명시 — 같은 문서를 같은 기준으로 재감수하면 살아있는 결함은 재발견된다 ③ 재도출의 한계 수용 명시: 이미 해소된(죽은) 결함은 영영 미확인이나 정의상 무해 — 이 잔여 수용을 문서에 기록 ④ 기회적 발굴: M0 감수 원문이 당시 작업 기록에 남아 있으면 소급 보존, 실패 무방.

**N8. 부수 2건.** ① 재료 명세 스키마의 `reader/schemas/` 배치 추인 + 경계 규칙 명문화: "**이식 단위(독해층)에 속하는 계약 = `reader/schemas/`, 파이프라인 전용 계약(형식 시트·판정 서식·봉투·화행 술어) = `contracts/`**" ② pytest: 리포 로컬 가상환경(uv) 생성 + pytest 설치 + 의존성 파일 기록(재생성 가능), `pytest --version` 실출력 첨부.
