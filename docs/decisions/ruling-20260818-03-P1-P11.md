## §1 재정 원문 (2026-08-18 후반)

**P-1 (구 B-03 해소).** Markush·조건부·수단항·카테고리 전환의 typed operator는 **N14 범위에서 제외**한다. 이 4구조를 만나면: 전문은 이미 보존되므로(R1) `unclassified`(구조 미분류) 표지 + CP1에 미분류 목록 노출 + 판정 행 계수. 입법은 실물 축적 시 건별 재정(배치 리뷰 상신 경로).

**P-2 (구 M-05 해소).** ⓐ 서지 구조 확장: 발명자·출원인·우선권을 **목록형**으로, 관할·공보 종별·분류 코드(IPC/CPC) 필드 추가 — 전부 서지면에서 결정론 복사. 근거: 단일 문서의 사실 구조(상대 불요 — N13의 관계 그래프 유보와 구별), C18 최우선일의 정확성 요건. ⓑ **층 분리**: 공유 코어(구성요소·접지·수치·서지 = 사실) / **프로젝트 확장 블록**(편집 판단 — `drop_signal` 등은 docent 네임스페이스 선택 블록으로 이동, historian 미기입). 경계 원칙 명문화: "공유 필수 필드는 프로젝트 간 동일 의미 — 프로젝트 고유 판단은 확장 블록에만" + **이 원칙을 정합 검사기 검사 항목으로**(문서 선언 아닌 기계 집행). 기존 산출물은 0.x 규율로 재조립.

**P-3 (수렴 임계, Owner 원리 육성 원장 등재).** 원리: *"결정론적으로 유일해야 하는 구조 사실(개수·종속항 서명)은 완전 일치를 트리거로, 해석 여지가 있는 부분(구성요소 입도·트리 조직)은 결함이 아니라 각 독해의 특성으로 기록·관찰한다."* 적용: 독립항 수·종속항 수·**종속항 서명축 = 완전 일치 트리거**(0.95→1.0 승격), element·tree-edges = 0.95 상신 트리거(`[가설]` 유지·배치 리뷰 교정 1순위), addition-attachment = **판정 제외·측정 전용**(부착 관례 입법 시까지). 미달 = 실패가 아니라 Owner 상신(계기 의미론). 상신 서식 = 수렴 리포트(축별 값·갈린 항목 — "결함 후보"가 아니라 "독해 프로파일" 프레임).

**P-4 (조기 수렴).** 수렴 검사를 분해 직후(접지 전)로 이동. 통과 시 **1회차(read-a)를 내용맹 결정론 규칙으로 정본 지정**(어떤 품질 비교·판정도 금지 — 근거: 수렴 통과=동치 선언, 판정자 부재, 재현성), read-b 산출은 convergence.json에 보존. **접지 이후 단계는 정본 1개만 진행.** retry(1)→escalate 경로를 조기 지점으로 이동.

**P-A (조기 drop = A₃, D4 문언 개정).** 조기 drop의 escalate를 폐지하고 **맹검 관찰 메모**로 강등: 분해 직후 레인이 서사 우려를 기록만(상신 없음·진행 계속), **최종 서사 평가 레인에는 비공개**(앵커링 방지), CP1에 병렬 제시. drop의 확정 재정은 **CP1에 통합**(재료 승인과 한 자리 — 완전 정보 위에서 1회). D4 문언을 "조기=맹검 기록, 확정=CP1 통합 재정"으로 개정. 목적 명시: 섀도 모드 — 청구항만 본 맹검 판단 vs 접지 후 최종 평가 vs Owner 재정의 3층 축적 = **historian 스크리닝 능력의 사전 훈련 데이터**. 메모 서식은 스크리닝 판단 기록형(판단 방향+근거 요지).

**P-U4 (메모 2회).** read-a·read-b **각자** 맹검 메모 작성(상호 맹검은 기존 격리가 자동 보장), **둘 다 기록·CP1에 둘 다 병기**(두 독립 관찰의 일치/불일치 자체가 신호). 섀도 원장 = `ledgers/`(재료 명세 계약면 밖): 메모 2건+최종 평가+Owner 재정을 한 행으로.

**P-B (수치 수확 = B₃′).** 수치 사실은 **접지 스팬 기반 전수 기계 수확**(⑤의 서사 편향 수확 폐지 — E1·전량 선편집 독트린의 일관 적용). **중요분 = 함의·포지셔닝 항목이 참조하는 수치**(역참조 도출 — LLM 중요도 판단 없음). CP1 표면 = 중요분 표시 + **전량 카운트 상시 표기**("전체 N건 — 참조 M건 표시, 미참조 접힘") + 미참조분 접힘. **미검토(미참조) 수치를 본문이 처음 인용하면 CP2에 "미검토 수치 사용" 플래그 자동 첨부**(모든 수치는 CP1 검토 또는 사용 시 검토 — 무검토 게시 경로 없음). 스키마 계약: 함의·포지셔닝 항목은 근거 수치를 참조 ID로 명시(참조 무결 검사 포함). 수확 누락은 회귀 변조본("숫자 심은 판")으로 상시 테스트. 보조 관찰: 반려 사유 분류에 `수치 보충` 유지(전수 수확이면 ≈0이어야 정상 — 위생 지표).

**P-C (지문 검사 위치 = C₁).** 진입+출구 이중 + **일반 원리: "모든 스테이지는 진입 시 선언된 입력의 지문을 검증한다"**. 불일치 = 품질 아닌 **환경 오류**(재시도·수정 루프 아님, 즉시 중단+진단). 출구 검사 목록은 P-4 이사 반영해 갱신.

**P-U1 (법전 스냅샷 = U1-A) + P-8 (구현 = 8-B).** 런은 **시작 시점의 git 커밋에 결박**된다 — 구현은 git worktree(그 커밋의 격리 체크아웃), run.yaml에 커밋 해시 기록. 계약·스키마·검증기·러너 전부 함께 고정("법/구현 경계 문제의 소멸"). 런 중 리포 개정은 다음 런부터(행위시법). **예외 없음**(긴급 수정 = Owner 명시 재시작만). 종료 시 커밋 비교로 **만료 통지**(개정 있었으면 완주 보고에 명기). 재개 런은 같은 커밋. 산출물은 런 작업장에 쓰고 완료 후 본 리포 반영(배선은 네 재량). 소급 재검 가능성(커밋 핀 재실행) 기록.

**P-U2 (원천 변경 복구).** 원천(patent.md + **도면 세트 전체** — 매니페스트 지문) 변경 감지 = 항상 **새 런**: source 재봉인 → 신 런, 구 런은 "superseded-by-source-change" 표시+상호 링크 보존(부분 복구·우회 스위치 금지 — 바이트 오프셋 특성상 부분 재사용은 정확성 위반). 진단 보고에 변경 내용(파일·규모) 명시. **테스트 자리 문제 처분**: 생산 경로에 지문 재계산 자리 금지, **테스트 하네스에만 픽스처 재봉인 도구**(표본은 자기완결 미니 세계).

**P-U3 (순서 집행 = U3-C).** 수렴 판정서를 **접지 스테이지의 선언 입력**으로 — 진입 조건 = 판정서 존재 ∧ (통과 ∨ Owner '계속' 봉투). 봉투는 해당 판정서 지문에 결속(R8 규격). read-b의 접지 레인 부재를 출구 레인 로그 검사에 추가.

**P-U5 (CP1 판독본 = U5-A) + D 지시.** 판독본 = **KR 틀 + EN 값**(장 제목·안내·라벨 = KR / 인용·해설·함의 값 = EN 그대로). 파생 번역(EN 값의 KR 요약) 금지 — KR 지원은 검토 중 대화로. 계약 명명 정정("KR 인간 판독본"→"CP1 판독본(KR 틀·EN 값)"). **render-parity 검사를 이 사양으로 구현**(EN 값이 뷰에 그대로 존재하는지 문자열 대조). 업그레이드 경로 중립 유지.

**E 지시.** 계약 문언 갱신: 분해 2회·접지 이후 1회(구 instances: 2 표기 정정).

**P-9 (예행 종료선 = 9-A).** 예행 런 = **strip 산출까지 완전 리허설**(CP2 변주 선택 포함, 게시만 제외). 예행 판정문에 미가동 게이트 목록 명기(N5 규율). 예행의 1급 산출물 = **통주 리포트**(단계별 소요·상신 이력·발견 결함·미가동 목록).

**P-11 (재감수 종결 = 11-A′).** 종결 판정 = **범위 고정**: 요구사항표 전 항목 + 재정 반영 대조의 **항목별 해소/미해소/부분 + 근거 표**. 전 항목 해소 = 종결. **범위 밖 신규 지적 = 종결 차단 아님** — 전량 원장 등재 + 해당 관할 다음 발주에 입력 편입(소실 금지). 단 신규 BLOCKER급 존재 시 자동 종결하지 않고 Owner 상신(종결/연장 재정). **이번 재감수부터 적용.**

**P-5 (전시물 산정식).** 파일 수 산정식 정식 승인: 단위=도면 파일(서브도면은 파일 단위·다각도 각각·**흐름도 포함**), 도면별 행 기록(소급 재계산). `[가설]` 유지 + 관찰 지표: "source 후보 수 vs DESIGN 채택 수" 비율(배치 리뷰).

**P-6 (계기 정족수 = B′).** **정족수 5/5.** 죽은 인스턴스만 재시도(상한은 네 재량, 살아있는 응답 보존). 상한 내 복구 실패 시 기계 강등 금지 — **Owner 상신**(대기/결측 진행/부분 인정 — ⓑⓒ는 육성 봉투). 결측·부분 런은 계기 상관 점검 표본 제외.

**P-7 (168h 창).** ±24h(비례 근거). 선택 스냅샷 부재 = "미수집"(결측·공허 어휘와 구별). 창 밖 기록 = "비표준 시점" 표시로 보존·표준 통계 제외.

## §3 이 재정이 바꾼 것 (원문에 대한 주석 — 재정 내용이 아니다)

*아래는 총괄(opus-director)이 원문을 하류에 옮기며 남기는 주석이며, 재정 본문이 아니다. 원문과 어긋나면 §1이 이긴다.*

**① `D-20260818-03` §2의 Owner 대기 5행이 전부 닫혔다.** 그 표는 "총괄이 닫을 수 없음"으로 다섯 줄을 올렸고, 이 재정이 다섯을 각각 처분했다 — B-03은 **제외**로(P-1), M-05는 **확장 + 층 분리**로(P-2), 수렴 임계는 **축별 차등**으로(P-3), 조기 수렴은 **이동**으로(P-4), 이월 3건은 P-5·P-6·P-7로. 남은 미해소 BLOCKER는 B-04(통주 미실행) 하나이며 그것은 재정 사항이 아니라 **실행**이다.

**② P-1은 규칙을 만들지 않고 범위를 줄여 닫았다.** `D-20260818-03` §2-1은 "재정이 ⓐ 파싱 규칙을 입법하거나 ⓑ 이 항목을 N14 범위에서 제외해야 닫힌다"고 두 갈래를 올렸고, 재정은 ⓑ를 골랐다. 그 결과 `alternative-form`의 **도달 불능**은 결함이 아니라 **설계**가 된다 — 다만 침묵하지 않는다는 조건이 붙었다(표지·목록·계수 셋). 이것이 D7의 "정답이 존재하는 범위만 다룬다"를 규칙 신설이 아니라 **관할 축소**로 지킨 사례다.

**③ P-3이 수렴 검사의 의미론을 갈랐다.** 종전 6축은 전부 같은 무게의 pass/fail이었다. 이제 셋은 **법**(완전 일치), 둘은 **계기**(상신 트리거), 하나는 **관찰**(판정 제외)이다. `D-20260818-03` §2-3이 "세 축을 같은 무게로 읽지 마라"고 상신한 것에 대한 정확한 처분이며, 그 결과 `read.convergence`는 단일 판정이 아니라 **세 층의 보고서**를 낸다.

**④ P-4와 P-U3은 한 쌍이다.** P-4는 수렴을 앞으로 옮기고, P-U3은 그 판정서를 **접지의 진입 조건**으로 결속한다. 둘이 없으면 "앞으로 옮겼다"는 것이 실행 순서의 관습으로만 존재하고 기계가 강제하지 않는다. `read-b`의 접지 레인 **부재**를 레인 로그 검사에 넣으라는 지시가 그 강제의 반대편이다 — 정본 1개만 진행했다는 사실이 **로그에 없음으로** 증명된다.

**⑤ P-B는 D12(전량 선편집)의 논리를 수치로 확장한다.** 도면을 선택분만 편집하지 않는 이유와 수치를 서사가 고른 것만 수확하지 않는 이유는 같다 — 선택이 생성보다 앞서면 선택되지 않은 것이 존재조차 하지 않게 되고, 나중에 필요해졌을 때 되돌아갈 자리가 없다. 그래서 수확은 전수이고, **고르는 일은 역참조**가 한다.

**⑥ P-U1은 "법/구현 경계 문제의 소멸"이라는 표현으로 한 부류의 결함을 통째로 없앤다.** M1 내내 반복된 사고 형태가 "런이 도는 중에 계약이 바뀌어 무엇이 당시 법이었는지 되짚을 수 없다"였다. 커밋 결박은 그 물음을 성립하지 않게 만든다 — 런의 법은 언제나 `run.yaml`의 커밋 하나다.

**⑦ P-11이 이번 재감수부터 적용된다.** 종결 판정의 범위가 **요구사항표 + 재정 반영 대조**로 고정되었고, 그 밖의 신규 지적은 종결을 막지 못하되 **소실되지도 않는다**(전량 원장 등재 + 다음 발주 입력). 이것은 M0.6 → M1 재감수에서 반복된 "닫히지 않는 감수"의 구조적 처분이다. 다만 단서가 하나 붙는다 — **신규 BLOCKER급은 자동 종결시키지 않고 Owner 상신**이다.
