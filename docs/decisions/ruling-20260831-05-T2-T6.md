## §1 T2 (안건 ①) — 재요리 경로는 PD-M5 시점으로 이연

**채택 = 상신 §7 ① ⓑ.**

| | |
|---|---|
| **PD-M2 라운드에 넣는 것** | **절차 문서**(재요리 절차의 `reader/procedure/` 편입) — 문서는 실물 왕복을 요구하지 않는다 |
| **넣지 않는 것** | **재요리 경로의 집행 코드**(`material-defect.md` 수신 → `reject-upstream` → `spec_version +1` → 재동결) |
| **이연처** | **PD-M5**(DESIGN+COMPOSE) 착지 시점 — 반려를 **발행하는 쪽**이 그때 선다 |
| **사유(총괄 원안)** | 지금 지으면 **합성 `material-defect.md` 로만** 시험된다. 단위 시험은 서되 실물 왕복은 서지 않으며, 그 상태를 「구현되었다」로 적는 것이 SPEC §6.7 이 막으려는 형태(강제 범위의 과장)다 |

**★ 이 재정의 귀결 하나 — 라운드 범위 ≠ 모듈 종결.** 재요리는 **PD-M2 모듈의 요구사항으로 남는다.**
따라서 **다음 발주(PD-M2 라운드)가 완주해도 PD-M2 모듈은 종결되지 않는다.** PD-M2 모듈 종결은
재요리 경로가 실물 반려로 시험되는 **PD-M5 이후**다. 이것을 흐리면 PD-M1 이 벌한 과장 보고의 형태가
그대로 재현된다.

## §2 T3 (안건 ②) — B-1: 검사 대상을 기록본으로 옮긴다

**채택 = 상신 §7 ② ⓐ.** 재정 R1 이 「판정 시점의 이동」을 선행 재정 사항으로 지정한 자리의 처분이다.

| | |
|---|---|
| **결정** | **로그를 먼저 쓰고, 디스크 기록본을 검사한다.** 검사는 **하나로 유지**한다 |
| **현 상태** | 검사(`engine/stages/read.py:1561~1562`)가 **메모리 저널**을 보고, 실제 로그는 그 뒤 `finally`(`:1618`)에서 쓰인다 → **런 중 부정은 탐지 · 사후 편집만 탐지 밖** |

| **기각 사유(총괄 원안)** | ⓑ 는 같은 불변식에 검사를 두 벌 둔다. **두 벌이 생기면 한 벌은 반드시 낡는다** — 이 리포가 `engine/gitpin.py` 단일 진원 · 형식 파라미터 시트 · 화이트리스트(B-07)에서 반복 성문화한 원리다 |

되돌리기 비용을 **중간**으로 적은 것이 이 자리다.

## §4 T5 (안건 ④) — B-3: 「문서는 수를 적지 않는다」를 규율로 세운다

**채택 = 상신 §7 ④ ⓒ**(ⓐ + ⓑ 결합).

| | |
|---|---|
| **결정** | ① **산문에서 계수를 뺀다** ② 계수는 **자동 생성 블록 한 곳**에만 둔다 ③ **관문이 그 블록을 실측과 대조**하고 어긋나면 커밋을 막는다 |
| **실증(기각 ⓓ 의 근거)** | `441 → 452 → 464` 가 **한 라운드 안에서 두 번** 낡았고 **두 번 다 독립 감수가 잡았다.** 고치는 시점과 늘어나는 시점이 달라 라운드를 더 돌아도 반복된다 |
| **기각** | ⓐ 단독(규모를 잃는다) · ⓑ 단독(산문에 흩어진 수가 남는다) · ⓓ(현행 유지 = 「반복을 수용한다」는 선언) |

**★ T5 는 다섯 중 유일하게 설계 도전(ROUTING §2 A2 ②)의 대상이다.** 문서 자체의 성격을 바꾸는
**규범 신설**이기 때문이다. **해당 발주문은 M1b 심사 PASS 전에 착수·커밋하지 않는다.** 나머지
T2·T3·T4·T6 은 기존 규범 안의 공학 집행·시험이므로 M1a 재량으로 발주한다.

**★ 대조 대상 목록 자체가 낡을 자리라는 것을 함께 등재한다**(상신 §7 ④ ⓑ 열의 자기 지적). 이 규율이
그 위험을 없애지 못하며, 다만 **낡음을 커밋 전으로 옮긴다.** 발주문은 이 한계를 명기해야 한다 —
그러지 않으면 T5 자신이 「강제 범위를 넓게 말하는」 형태가 된다.

## §6 이 재정 5건이 정하지 **않은** 것

1. **PD-M6~M12** — 범위 밖. 게시 런 자격 3종(전 방어층 가동 · 도면 사용권 재정 · 템플릿 동결)도 그렇다.
2. **재정 Q4 배제 봉투 동결** — **PD-M4 까지 그대로다.** T1 이 PD-M4 를 뒤로 보냈으므로 동결 기간이
   길어졌고, 그 손실은 T1 ⒞ 에서 고지 후 채택되었다.
3. **`'854` M106 명명**(값 승인 · 명명 유보)과 **신설 검사 `read.lane-log-digest-value` 의 증명 범위
   경계** — 이월 상태 그대로. 재정 R1 이 다음 발주 필수 편입으로 못 박은 것은 B-1·B-2 이며 이 둘이
   아니다.
4. **좌석 배정·감수 의뢰 수** — 상신 §8 에 총괄 재량으로 기록되어 있으며 이 재정의 대상이 아니었다.
