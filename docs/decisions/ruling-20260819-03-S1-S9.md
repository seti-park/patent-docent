**이 파일의 지위.** §1 은 Owner 재정의 **원문**이다 — 다만 그 원문의 형태가 이번에는 **선택지 기호**다(`(a)`·`(b)`·`a`·`b`). 세션 리뷰 문답에서 항목별로 기호만 내려왔고, 그 기호가 무엇을 가리키는지는 같은 문답에 실려 있던 선택지 문안이 정한다. **기호는 원문이고 선택지 문안은 재구성본이다** — 이 구별을 지우면 총괄이 적은 선택지 문안이 Owner 의 문언으로 위장된다(재정 N6 규율 2). §2 가 그 재구성이며, 어긋나면 §1 이 이긴다.

**안건 ID 부여의 격 — 총괄의 기재이지 Owner 의 것이 아니다.** 이번 재정에는 Owner 가 붙인 안건 문자가 없다(세션 문답의 항목 번호 ①~⑨ 뿐이다). 원장 규율 4가 안건 ID 를 필수 항목으로 두므로 총괄이 **S 계열**을 부여했고, 대응은 `① = S1 … ⑨ = S9` 로 고정한다. 앞선 계열(D·R·N·P·Q·H)과 겹치지 않는 미사용 문자를 골랐을 뿐이며 **번호에 의미는 없다.** 이 문단이 있는 이유는 다음 사람이 `S3` 을 Owner 가 발화한 이름으로 오해하지 않게 하기 위함이다.

### S3 — Q5 ② 입법 초안의 조건부 승인 (③ = ⓑ) · **앵커 결함 3건 교정**

| **이행** | ① 패턴 3건 교정 ② **`unresponsive to` 반례 golden** 으로 오탐 부재를 실증 ③ 규칙 파일의 `ruling:` 필드를 *초안*에서 **재정 확정 문언**으로 갱신 |

| **결정 근거(문답에서 오간 논거)** | **전수성 > 순도.** 배제를 넓혀 순도를 올리는 방향은 **진짜 값을 삼키는 위험**을 동반하며, 그 손실은 `skipped[]` 로도 잘 드러나지 않는다. 실제로 같은 라운드에서 `boundary-right` 배제가 진짜 exponent bit-width 넷(`5b·4b·3b·2b`)을 먹고 있었던 것이 실측되었다 — **배제 과광화가 진짜 값을 삼키는 위험**이 이 재정의 결정 근거다 |
| **이행 ①** | 요구사항표 **P-B 행 = 해소**. 근거 = 요건 문언 다섯이 전부 구현·반증을 든다 |
| **이행 ②** | **알려진 아티팩트 M87~M89 의 건별 봉투 배제 입법** — 사유를 명기하고 `[가설]` 태그를 달며, **이번 재정이 근거**다. 이것은 S2 가 세운 기준을 지킨 **정규 선상신-승인**이다(값 공간을 바꾸는 판단이므로 재량으로 하지 않았다) |
| **이행 ③** | **배제가 진짜 값을 먹지 않는다는 반례 golden 을 동반**한다(예: `between 1 and 2` 의 보존 실증). 넓히는 입법에는 반례가 따라야 한다는 것이 이 재정의 조건이다 |

### S8 — 회수 판정의 격 (⑧ = ⓑ) · **P-11 부칙 4조**

| 항목 | 내용 |
|---|---|
| **논점** | 사망한 감수 세션의 판정을 `rollout-*.jsonl` 에서 회수한 산출을, 종결 판정의 근거로 쓸 수 있는가. 쓸 수 있다면 어떤 격으로 |
| **선택지(재구성)** | ⓐ 회수분은 참고 자료 — 판정표에 쓰지 않는다 / ⓑ **층위를 나눈 4조로 규정한다** |
| **재정** | **ⓑ** |
| **부칙 1** | **앵커가 있는 지적은 격과 무관하다.** 파일·행 좌표가 붙은 지적은 회수분이든 완주분이든 **실재 확인으로 판정한다** — 좌표가 실재하면 지적도 실재한다 |
| **부칙 2** | **판정표 자격은 `complete` 와 `recovered` 에 있다.** 단 회수분의 **미확인 표기 항목은 커버리지에서 제외**하고, 판정표에 **격을 표시할 의무**가 붙는다. `partial`(부분 산출)은 **참고 전용**이며 판정표에 오르지 않는다 |
| **부칙 3** | **같은 항목에 상반 판정이 오면 자동 승자는 없다.** 둘 다 등재하고 **불일치를 표시**한 뒤 **상신**한다(선례 = 재정 Q8 ④ — 원천이 두 말을 할 때 하나를 고르지 않고 둘 다 적는다) |
| **부칙 4** | **회수분만으로 진행할 수 있다.** 격을 표시한 채 진행하며, **재실행 여부는 발주자의 판단**이다 — 회수가 되었다는 사실이 재실행 의무를 만들지 않는다 |
| **이행** | 부칙을 원장에 등재하고 `docs/SPEC.md` §8.3 감수 절차에 반영한다 |
