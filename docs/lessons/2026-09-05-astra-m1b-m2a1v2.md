**T3·G-5·반경 판정**

T3의 **게시 → 디스크 재독 → 기존 검사 한 벌**은 정확히 옮겼다. 검사 행이 저널에 추가된다는 전제는 거짓이며, 무변조 경로의 재기록은 내용상 멱등이다. 그러나 파일만 B로 변조한 경우 재기록은 B를 A로 지우므로 v2의 게시 후 덮어쓰기 금지는 타당하다. 정상 런은 A, 변조 탐지 런은 실제 검사 입력 B가 사후 감사 기록으로 남는다. 보장 시점은 **게시 후 재독까지**이며 검사 종료 이후의 임의 편집 탐지까지 뜻하지 않는다.

ⓐ의 실제 `request.md`·비공백 `request_digest`·파일만 변조하는 writer 후행 훅은 올바르다. ⓑ는 **`read_run`만** 비정본으로 바꾸고 `lane_id`·지문·요청 파일을 유지하면 형태만 실패하도록 만들 수 있다.

G-5 분리는 타당하다. v2에는 종결 가드·원장 중복 방지 구현·포인터 변경·G-5 백로그 집행 표기가 남아 있지 않다. 남은 언급은 제외 선언과 현행 경로 설명이다. 다만 **무접촉은 부작용 0이라는 뜻이 아니다**. 재독 `StageError`에서도 현행 `terminated=True`와 `finally`가 유지되므로 메모가 있으면 원장에 쓰고 포인터도 쓴다. 이를 차단하면 G-5 상태·기입 정책을 다시 건드린다.

형상 수락에는 골격 ⒀ 추기가 금지한 전역 문자열 무일치 조건이 없다. 다만 파일 수는 행위 증거가 아니며, 시작 상태 대비 허용 변경 확인으로 사용해야 한다. MH-3의 호출 호환성을 유지하면 기존 시험 편집으로 반경을 넓힐 이유도 없다.

현재 B-1을 닫기 위해 새 임계값·검사 id·실패표 행이 필요하다는 근거는 없다. **재독 결함을 새 품질 판정으로 바꾸거나 원장 기입을 억제하는 선택을 하면 그때는 별도 결정 경계다.**
